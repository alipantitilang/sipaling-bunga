# GENERATION RULES

## Pipeline

```text
INPUT → Flower Identification → Meaning Retrieval → Connection Mapping
→ Interpretation → Narrative Generation → Sunday Garden Copy → Validation
```

## Rules

- Name + flower may produce `i[r]` as a discovery hypothesis.
- Do not invent `mr[m]`.
- Gardener-provided `mr[m]` is authoritative for its personal meaning.
- `i[r]` is evidence, not confirmed truth.
- Gardener controls basis/goal/meaning when correcting `i`.
- Gardener may freely replace `mr` through correction.
- AI retains Sunday Garden editorial style.
- Maturity is field-level and asynchronous.
